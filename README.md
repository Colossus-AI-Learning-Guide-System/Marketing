## 📚 About ColossusAI

ColossusAI is an innovative learning platform that transforms how you interact with information. Using advanced AI technology, we create visual roadmaps from your documents, making learning more intuitive and engaging. Our platform helps you navigate complex knowledge with ease, whether you're a student, researcher, or professional.

## 🛠️ Technologies Used

### Frontend
- ![React](https://img.shields.io/badge/-React-61DAFB?style=flat-square&logo=react&logoColor=black) **React.js** - UI components and state management
- ![Next.js](https://img.shields.io/badge/-Next.js-000000?style=flat-square&logo=next.js&logoColor=white) **Next.js** - Server-side rendering and routing
- ![TypeScript](https://img.shields.io/badge/-TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white) **TypeScript** - Type-safe code
- ![Tailwind CSS](https://img.shields.io/badge/-Tailwind_CSS-38B2AC?style=flat-square&logo=tailwind-css&logoColor=white) **Tailwind CSS** - Styling and responsive design
- ![Framer Motion](https://img.shields.io/badge/-Framer_Motion-0055FF?style=flat-square&logo=framer&logoColor=white) **Framer Motion** - Animations and transitions
- ![Three.js](https://img.shields.io/badge/-Three.js-000000?style=flat-square&logo=three.js&logoColor=white) **Three.js** (@react-three/fiber, @react-three/drei) - 3D visualizations

### UI Components
- ![Radix UI](https://img.shields.io/badge/-Radix_UI-161618?style=flat-square&logo=radix-ui&logoColor=white) **Radix UI** - Accessible UI primitives
- ![Lucide](https://img.shields.io/badge/-Lucide_React-5468FF?style=flat-square&logo=lucide&logoColor=white) **Lucide React** - Icon library
- ![Heroicons](https://img.shields.io/badge/-Heroicons-6875F5?style=flat-square&logo=heroicons&logoColor=white) **Heroicons** - Additional icon set

### Backend
- ![Node.js](https://img.shields.io/badge/-Node.js-339933?style=flat-square&logo=node.js&logoColor=white) **Node.js** - Server environment
- ![Nodemailer](https://img.shields.io/badge/-Nodemailer-339933?style=flat-square&logo=nodemailer&logoColor=white) **Nodemailer** - Email functionality

### AI Integration
- ![OpenAI](https://img.shields.io/badge/-OpenAI_API-412991?style=flat-square&logo=openai&logoColor=white) **OpenAI API** - AI-powered features

### Deployment
- ![Heroku](https://img.shields.io/badge/-Heroku-430098?style=flat-square&logo=heroku&logoColor=white) **Heroku** - Cloud hosting platform
